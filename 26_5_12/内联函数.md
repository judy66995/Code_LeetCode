# 内联函数 inline（极简人话版）
![alt text](image.png)
## 1. 是什么
**加了 inline 关键字的小函数**，叫内联函数。

## 2. 核心作用
普通函数：**调用 → 跳转 → 执行 → 返回**，有跳转开销、慢一点。
内联函数：**编译时直接把函数代码原地复制粘贴过来，不跳转、不调用**，速度更快。

## 3. 直白例子
普通函数调用：
```c
void add(){ a++; }
add();  // 要跳过去执行，再跳回来
```

内联函数：
```c
inline void add(){ a++; }
add();
```
编译器直接把 `add()` 替换成一行 `a++;`，**没有函数调用过程**。

## 4. 特点
1. 适合**代码很短、频繁调用**的小函数
2. 省去调用开销，**运行更快**
3. 代码会变多（原地复制），**占体积**
4. 大函数、循环、递归**不能用内联**

## 5. 口诀
**小函数加 inline，原地粘贴不跳转，提速省调用，体积会变大。**

## 6. 人话区别
- 普通函数：有调用开销，代码少
- 内联函数：无调用开销，速度快，代码体积变大
