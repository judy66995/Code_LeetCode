
# 一、命名空间（namespace）是什么？
**一句话：**
**命名空间 = 给代码加一个“姓氏”，避免重名打架。**

格式：
```cpp
namespace 名字 {
    变量、函数、类…
}
```
实例：
```
#include <iostream>
using namespace std;

// 命名空间 1：小明写的代码
namespace XiaoMing {
    int age = 10;   // 小明的 age

    void sayHello() {
        cout << "我是小明！" << endl;
    }
}

// 命名空间 2：小红写的代码
namespace XiaoHong {
    int age = 12;   // 小红的 age（名字一样，但不冲突！）

    void sayHello() {
        cout << "我是小红！" << endl;
    }
}

int main() {
    // 使用小明的东西
    cout << "小明的年龄：" << XiaoMing::age << endl;
    XiaoMing::sayHello();

    // 使用小红的东西
    cout << "小红的年龄：" << XiaoHong::age << endl;
    XiaoHong::sayHello();

    return 0;
}
```

# 二、为什么要有命名空间？（超级重要）
因为**多人写代码、很多库、很多函数，名字一定会重复！**

## 生活例子
你们班有 **两个张三**：
- 张三（姓王）
- 张三（姓李）

如果老师只喊：**“张三！”**
→ **两个人都会回头，分不清是谁！**

这就叫**命名冲突**。

解决方法：
- 喊 **王::张三**
- 喊 **李::张三**

**:: 就叫“作用域解析符”**

# 三、回到 C++
C++ 官方写了一大堆工具：
- string
- vector
- cout
- cin
- sort

这些官方工具**全部放在一个叫 `std` 的命名空间里**。

所以：
```cpp
std::string
std::cout
std::vector
```

意思就是：
**我要用官方（std）里的 string / cout**

---

# 四、代码里的这句话
```cpp
using namespace std;
```

意思是：
**从现在开始，我所有代码默认都用 std 里的东西，不用每次写 std::**

于是你可以写：
```cpp
string str;     // 等价于 std::string
cout << "hi";   // 等价于 std::cout
```

# 五、命名空间的真正作用（总结）
1. **避免名字冲突**
   你写了一个函数叫 `open()`
   系统也有一个函数叫 `open()`
   不加命名空间会**直接报错**。

2. **代码分类**
   官方代码放 `std`
   你的项目代码放 `myProject`
   驱动代码放 `driver`
   清晰不乱。

3. **大型项目必备**
   嵌入式Linux、内核、大型软件全都用命名空间。

---

# 六、总结
- **namespace = 姓氏**
- **std = 官方姓氏**
- **std::string = 官方版字符串**
- **using namespace std = 以后直接喊名字，不用带姓氏**
