# 基本计算器示例 
`(1+(4+5+2)-3)+(6+8)`  

---

# 先记住 4 个变量
1. **result** = 当前算出来的结果
2. **sign** = 符号（1=正，-1=负）
3. **num** = 当前正在读的数字
4. **stack** = 遇到“`(`”时保存现场，遇到“`)`”恢复现场

---

# 初始状态
```
result = 0
sign = 1
num = 0
stack = 空
```

---

# 开始逐个字符跑！
表达式：
```
( 1 + ( 4 + 5 + 2 ) - 3 ) + ( 6 + 8 )
```

---

# 1. 字符 `(`
- 把当前 `result=0` 和 `sign=1` 压栈
- 重置：`result=0，sign=1，num=0`

**栈现在：** `[(0,1)]`

---

# 2. 字符 `1`
- 是数字
- `num = 0*10 + 1 = 1`

---

# 3. 字符 `+`
- 先结算：`result += sign * num`
- `result = 0 + 1*1 = 1`
- `sign = 1`
- `num = 0`

---

# 4. 字符 `(`
- 把当前 `result=1` 和 `sign=1` 压栈
- 重置：`result=0，sign=1，num=0`

**栈现在：** `[(0,1), (1,1)]`

---

# 5. 字符 `4`
- `num = 4`

---

# 6. 字符 `+`
- `result += 1*4 → result=4`
- `sign=1`
- `num=0`

---

# 7. 字符 `5`
- `num=5`

---

# 8. 字符 `+`
- `result += 1*5 → result=9`
- `sign=1`
- `num=0`

---

# 9. 字符 `2`
- `num=2`

---

# 10. 字符 `)`
- 先结算：`result += 1*2 → result=11`
- 出栈：拿到 `(1, 1)`
- `result = 1 + 1*11 = 12`
- `num=0`

**栈现在：** `[(0,1)]`

---

# 11. 字符 `-`
- `result += 1*0 → 不变`
- `sign = -1`
- `num=0`

---

# 12. 字符 `3`
- `num=3`

---

# 13. 字符 `)`
- 结算：`result += (-1)*3 → 12 - 3 = 9`
- 出栈：拿到 `(0, 1)`
- `result = 0 + 1*9 = 9`
- `num=0`

**栈现在：空**

---

# 14. 字符 `+`
- `result += 1*0 → 不变`
- `sign=1`
- `num=0`

---

# 15. 字符 `(`
- 压栈 `(9, 1)`
- 重置 `result=0, sign=1, num=0`

**栈：[(9,1)]**

---

# 16. 字符 `6`
- `num=6`

---

# 17. 字符 `+`
- `result += 1*6 → 6`
- `sign=1`
- `num=0`

---

# 18. 字符 `8`
- `num=8`

---

# 19. 字符 `)`
- 结算：`result += 1*8 → 14`
- 出栈：拿到 `(9, 1)`
- `result = 9 + 1*14 = 23`
- `num=0`

---

# 遍历结束！最后一步
```
result += sign * num → 23 + 0 = 23
```

# 🎉 最终答案：23

---

# 超级大白话总结
- **`(` = 保存现场 → 进栈**
- **`)` = 恢复现场 + 把括号结果算进去 → 出栈**
- **数字 = 攒起来变成整数**
- **`+/-` = 结算前面的数字**

这就是**嵌入式/内核中最常用的栈式嵌套解析逻辑**！
