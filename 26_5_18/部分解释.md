`arr.resize(capacity);` 这行代码，是 **给 `vector` 数组设置/调整它的大小**，通俗点讲，就是“给这个数组申请能放下 `capacity` 个元素的内存空间”。

---

### 一、先搞懂它的作用
这里的 `arr` 是 `vector<int>` 类型（C++ 里的动态数组），它默认不会自动扩容到你想要的大小，所以需要手动 `resize`：

- 执行 `arr.resize(capacity);` 之后，`arr` 就变成了一个**长度为 `capacity` 的 `int` 数组**，每个元素初始值都是 `0`。
- 对应你这个循环队列，`capacity` 是 `k+1`，所以它会帮你申请 `k+1` 个 `int` 元素的空间，刚好满足“牺牲一个空位区分队空/队满”的需求。

---

### 二、和嵌入式C语言里的对比
这行代码，等价于在嵌入式C里写的：
```c
int *arr = (int *)malloc(sizeof(int) * capacity);
```
区别是：
- `vector` 的 `resize` 会自动帮你**初始化元素为0**，还会自动管理内存（不用手动 `free`）
- C的 `malloc` 只会申请空间，不会初始化，用完还要手动释放

---

### 三、在你这段代码里，它的具体流程
```cpp
MyCircularQueue(int k) {
    capacity = k + 1;
    arr.resize(capacity); // 关键这一行
    front = 0;
    rear = 0;
}
```
以 `k=3` 为例：
1.  `capacity = 3+1 = 4`
2.  `arr.resize(4);` → 把 `arr` 变成长度为4的数组，初始值 `[0,0,0,0]`
3.  后面的 `enQueue`、`deQueue` 操作，就都是在这个长度为4的数组上进行的。

---

### 四、补充：resize 的两种常见用法
1.  **扩容**：比如原来 `arr` 长度是2，`resize(4)` 之后，数组变成4个元素，新增的2个默认初始化为0
2.  **缩容**：如果原来长度是4，`resize(2)` 之后，数组会被截断成前2个元素，后面的被丢弃

你这里用的是第一种：**初始化扩容**，给队列分配好固定大小的缓冲区。

---

### 五、嵌入式视角理解
这行代码本质就是**给你的环形缓冲区分配固定大小的内存**，和你在嵌入式里定义一个全局数组 `int arr[4];` 效果是一样的，只是用 `vector` 更方便、安全，还能自动管理内存。
