# 中序遍历
## 1. 一句话核心
二叉树遍历有**固定顺序**，中序遍历就是：
**先看左孩子 → 再看自己 → 最后看右孩子**
口诀：**左 → 根 → 右**

---
## 2. 先搞懂树的结构
拿我们刚才的例子：
```
      3     ← 根节点（自己）
     / \
    1   4   ← 左孩子1，右孩子4
     \
      2     ← 1的右孩子
```
- 3 的**左**：1
- 3 的**右**：4
- 1 的**左**：无
- 1 的**右**：2

---
## 3. 中序遍历怎么一步步走？（严格按：左→根→右）
### 遍历节点 3
1. 先遍历**左子树（1）**
   - 遍历节点1：先看左（无）→ 看自己（1）→ 看右（2）
     - 遍历节点2：左无 → 自己（2）→ 右无
   → 输出：`1，2`
2. 再看**自己（3）** → 输出：`3`
3. 最后遍历**右子树（4）**
   - 节点4：左无 → 自己（4）→ 右无
→ 输出：`4`

### 最终中序遍历结果
`1 → 2 → 3 → 4`
**天然从小到大排好序！**
这就是二叉搜索树的特性。

---
## 4. 三种遍历对比
- **前序遍历**：根 → 左 → 右（先看自己）
- **中序遍历**：左 → 根 → 右（中间看自己）
- **后序遍历**：左 → 右 → 根（最后看自己）

---
## 5. 嵌入式Linux为什么必考中序遍历？
1. Linux内核里**红黑树、设备树、进程管理树**，全靠中序遍历实现**有序查找**
2. 遍历必须用**栈+循环**（不能递归，递归会栈溢出），和我们刚才写的代码完全一致
3. 内核源码里大量这种写法，是底层开发基本功
