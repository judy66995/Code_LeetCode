# 二叉搜索树（BST,binary search tree）
## 1. 先记住一条铁则（最重要）
**每个节点：左边所有数 < 自己 < 右边所有数**

二叉搜索树又称为二叉排序树，它或者是一颗空树，或者是满足以下性质的二叉树：
若它的左子树不为空，则左子树的所有节点的值都小于根节点的值
若它的右子树不为空，则右子树的所有节点的值都大于根节点的值
它的左右子树也要满足二叉搜索树，并且通常二叉搜索树不能有重复值

### 举个例子
```
      3
     / \
    1   4
     \
      2
```
- 根节点是 3
  - 左边：1、2 都比 3 小
  - 右边：4 比 3 大
- 节点 1：右边 2 比它大
- 节点 4：左右都空

完全符合：**左小、右大**

---

## 2. 二叉树 vs 二叉搜索树
- **普通二叉树**：数字随便放，大小没有规律
- **二叉搜索树（BST）**：严格遵守 **左小右大**，自带排序功能

## 3. 它最牛的特点（直接对应230题）
**中序遍历（左→根→右），遍历结果一定从小到大排序**
上面的树中序遍历：
`1 → 2 → 3 → 4`
天然排好序！
所以第 k 个遍历到的数，就是**第 k 小**的数，这就是230题的核心原理。

---

## 4. 嵌入式/Linux里有什么用？
Linux 内核里大量用 **二叉搜索树 / 红黑树（增强版BST）**
- 管理进程
- 管理文件
- 管理驱动设备节点
- 管理网络连接

好处：**查找、插入、删除速度极快**，比数组链表快很多。

---

## 5. 一句话总结
**二叉搜索树 = 自带排序规则的二叉树，左边小右边大，中序遍历直接升序。**
