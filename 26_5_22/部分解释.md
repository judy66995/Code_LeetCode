int halfLen = (totalLen + 1) / 2; 这行代码是向上取整，还是向下取整？

# 一句话答案
```cpp
int halfLen = (totalLen + 1) / 2;
```
这行代码的作用是：
# **对 totalLen 进行【向上取整】除以 2**

---

# 为什么是向上取整？
因为在 C++ 里，整数除法 **`/` 是自动向下取整**的。
想实现 **向上取整**，公式就是：
## **(A + B - 1) / B**

这里 B=2，所以公式变成：
## **(A + 1) / 2**

---

# 举例一看就懂
我们代入数字：

1. **totalLen = 3（奇数）**
   (3 + 1) / 2 = 4/2 = **2**
   → 3/2=1.5 → 向上取整 = **2**

2. **totalLen = 4（偶数）**
   (4 + 1) / 2 = 5/2 = **2**
   → 4/2=2 → 向上取整 = **2**

3. **totalLen = 5**
   (5+1)/2=3 → 正确向上取整

---

# 这道题里为什么要向上取整？
因为：
- **总长度奇数**：左边要**多放一个数**
- 中位数 = 左边最大的那个数

`halfLen` 代表：
## **左边一共要放多少个数字**
