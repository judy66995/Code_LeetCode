for (auto& interval : ans1) 这句代码里的&是什么意思？

# 一句话大白话
```cpp
for (auto& interval : ans1)
```
这里的 **`&` = 引用**
**意思：直接用原来的数据，不复制一份，省内存、省时间！**

---

# 1. 先讲 `auto`
`auto` 是让编译器**自动识别类型**，不用你手写：
- 不用写 `vector<int>`
- 直接 `auto` 就行，省事

---

# 2. 重点：`&` 到底干嘛？
## 不加 &：
```cpp
for (auto interval : ans1)
```
→ **每次循环都复制一份数据**
→ 费时间、费内存

## 加 &：
```cpp
for (auto& interval : ans1)
```
→ **直接用原来的数据，不复制**
→ **快、省内存、嵌入式必备！**

---

# 3. 超级通俗比喻
你有一本**笔记本**（ans1 数组）：

- **不加 &** = 每次都把一页**复印下来**看
- **加 &** = **直接翻开原页看**

**& 就是“直接看原件”，不复印！**

---

# 4. 在这道题里的实际意义
`interval` 是一个区间 `[1,6]`
- 加 `&` → 直接用原来的区间
- 不加 → 复制一份新的，浪费性能

**嵌入式Linux开发特别在意内存和速度，所以几乎都写 &**

---
