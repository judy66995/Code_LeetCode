# **什么是 Lambda 表达式（匿名函数）？**

你只要记住一句话：
# **Lambda = 一次性使用的、没有名字的临时小函数**

---

# 一、先搞懂：什么是“匿名”？
平时我们写函数，**必须起名字**：
```cpp
// 有名字：compare
int compare(int a, int b) {
    return a < b;
}
```

但 **Lambda 没有名字**，直接写在要用的地方，用完就丢。
```cpp
// 没名字，直接用
[](int a, int b) { return a < b; }
```

---

# 二、为什么要用 Lambda？
因为**有些函数只用一次**，没必要专门写一个完整函数，太麻烦！

比如你那道题的排序：
```cpp
sort(points.begin(), points.end(), 【排序规则】);
```
这个**排序规则**只在这里用一次，
直接写个**匿名小函数**最方便！

---

# 三、Lambda 长什么样？（逐部分拆解）
```cpp
[](vector<int>& a, vector<int>& b) {
    return a[1] < b[1];
}
```

拆成 3 部分：

## 1. `[]`  →  标记“我是 Lambda”
只要看到 `[]`，就知道这是匿名函数。

## 2. `(vector<int>& a, vector<int>& b)`  →  参数
和普通函数一样，写**要传入什么参数**。
这里就是：传入两个气球 a 和 b。

## 3. `{ return a[1] < b[1]; }`  →  函数体
要做什么事：
**比较两个气球的右端点，小的排前面。**

---

# 四、最关键：它在你代码里到底干嘛？
```cpp
sort(..., [](a, b) { return a[1] < b[1]; });
```

大白话翻译：
> **sort 你帮我排序，但我要自定义规则：
> 按照每个气球的【右端点】从小到大排！**

---

# 五、超级通俗比喻
你去饭店吃饭：
- 普通函数 = **固定菜单**（提前做好，多次用）
- **Lambda = 临时点一道菜**（只用一次，现做现吃）

---

# 六、一句话终极总结
# **Lambda = 临时用一次、没有名字、直接写在代码里的小函数**
在你这道题里，它的作用只有一个：
# **告诉 sort：按区间右端点从小到大排序！**
