# 整行代码的作用
```cpp
sort(points.begin(), points.end(), [](vector<int>& a, vector<int>& b) {
    return a[1] < b[1];
});
```

**作用：把所有气球，按【右端点】从小到大排序！**
也就是：
谁的**结束位置更小**，谁排在前面。

# 一、拆成 4 部分逐行解析

## 1. sort( )
C++ 的**排序函数**，用来给一组数据排序。

---

## 2. points.begin()
指向**数组的第一个元素**
告诉 sort：**从这里开始排**

---

## 3. points.end()
指向**数组最后一个元素的后面**
告诉 sort：**排到这里结束**

---

## 4. 最关键的：[ ](vector<int>& a, vector<int>& b) { return a[1] < b[1]; }
这叫 **Lambda 表达式（匿名函数）**
作用：**告诉 sort 按照什么规则排序**

---

# 二、重点解析：比较函数是什么意思？

```cpp
[](vector<int>& a, vector<int>& b) {
    return a[1] < b[1];
}
```

## 翻译成人话：
- `a` 和 `b` 是**两个气球**
- 每个气球是 `[起点，终点]`
- `a[1]` = a 的**终点（右端点）**
- `b[1]` = b 的**终点（右端点）**

## 规则：
**如果 a 的终点 < b 的终点 → 让 a 排在 b 前面**
→ 最终结果就是：**终点从小到大排列**

# 四、为什么必须按**右端点**排序？
因为我们要**一支箭射爆最多气球**
策略是：
**箭射在当前气球的最右端 → 能覆盖最多后面重叠的气球**

如果不按右端点排序，就无法用贪心算法得到最少箭！

# 一、先搞懂：每个气球是什么？
在代码里，**一个气球 = 一个数组 `vector<int>`**

比如：
```
气球 = [1, 6]
```
- `气球[0]` = 左端点 1
- `气球[1]` = **右端点 6**

所以：
- **a[1] = a 气球的右端点**
- **b[1] = b 气球的右端点**

# 二、`sort` 排序的规则是什么？
C++ 的 `sort` 函数有一个**铁律**：

## 你给它一个**比较函数**，它会问你：
### **“a 应该排在 b 前面吗？”**

### 你回答：
- **return true** → **a 排前面**
- **return false** → **b 排前面**

# 四、超级直观例子一看就懂！

假设有两个气球：
```
a = [2, 8]    a[1] = 8
b = [1, 6]    b[1] = 6
```

执行判断：
```
a[1] < b[1] → 8 < 6 → false
```

**return false**
→ **a 不排前面**
→ **b 排前面**

结果：
`[1,6]` 在前
`[2,8]` 在后

✅ **从小到大！**

# 六、你只要记住这个万能口诀
- **`<`  → 从小到大（升序）**
- **`>`  → 从大到小（降序）**

```
return a[1] < b[1];  → 小的在前
return a[1] > b[1];  → 大的在前
```
