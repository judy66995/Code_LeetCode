# 一、先给一句话通俗定义
**移位 = 把二进制整体往左/右搬位置（乘/除 2^n）**  
**掩码 = 一个“过滤器”，用 & 只留下你想要的那几位，其他清零**

合在一起：  
**用移位把数据搬到正确位置 → 用掩码精准选中某几位 → 实现对寄存器/变量的“按位精准操作”**

嵌入式里几乎所有**GPIO、寄存器、中断、时钟配置**全靠它。

---

# 二、先分别讲：移位、掩码

## 1）移位（<< 左移、>> 右移）
就是把二进制数整体平移，空位补0。

- **左移 <<**：往左挤，右边补0 → 相当于 ×2ⁿ
  ```
  5 = 0101
  5 << 2 → 010100 = 20   （×4）
  ```

- **右移 >>**：往右挤，左边补0 → 相当于 ÷2ⁿ
  ```
  5 = 0101
  5 >> 1 → 0010 = 2     （÷2）
  ```

**嵌入式用途**：
- 把某一位“搬到”指定位置，方便做掩码
- 快速乘除2的幂（比乘法快）

---

## 2）掩码（mask，就是一个特制二进制数）
掩码 = **只留你关心的位是1，其他全是0**，用来当“筛子”。

例子：
- `0x01` → `00000001` → 只筛最低位（bit0）
- `0x08` → `00001000` → 只筛 bit3
- `0xF0` → `11110000` → 只筛高4位

**用法：&（按位与）**
```
数据 & 掩码 → 只保留掩码为1的那些位，其余清零
```

例子：
```
数据： 1011 0101
掩码： 0000 1111
结果： 0000 0101   （只保留低4位）
```

**嵌入式用途**：
- 读寄存器某几位状态
- 改寄存器某几位，不影响其他位

---

# 三、“移位 + 掩码”组合拳（核心！）
**套路永远是三步：**
1. **移位**：把要操作的位，移到对齐位置
2. **掩码**：用 & 筛出目标位
3. **（可选）再移位**：把结果移回低位方便使用

### 真实嵌入式例子：读取寄存器 bit6
寄存器 `REG`：`1011 0101`（8位）  
要读 **bit6**（从0数，第6位）

#### 第一步：造掩码（1 左移 6 位）
```
1 << 6 → 0100 0000   （掩码：只有 bit6=1）
```

#### 第二步：移位+掩码（取出 bit6）
```
REG & (1 << 6)
= 1011 0101 & 0100 0000
= 0100 0000   （非0 → bit6=1）
```

#### 第三步：再右移，把结果变成 0/1
```
(REG & (1 << 6)) >> 6 → 0000 0001 → 1
```

**一句话：移位把1放到目标位 → 掩码把目标位捞出来 → 再移位变成0/1**

# 四、回到 LeetCode 201：为什么它也是“移位+掩码”思路？
题目：`[left, right]` 所有数按位与 = **公共前缀，后面全0**

代码：
```c
while (left != right) {
    left >>= 1;   // 右移：把低位扔掉
    right >>= 1;
    shift++;
}
return left << shift; // 左移：把公共前缀移回去
```

### 用“移位+掩码”理解：
- **循环右移** = 不断把**非公共的低位“掩码掉”（扔掉）**
- 直到 `left==right` = **只剩公共前缀（有效位）**
- **最后左移** = 把公共前缀恢复到原来的高位位置

本质：**用移位代替显式掩码，只保留有效公共位，其余清零**——嵌入式寄存器“只保留有效位”的标准思路。

# 五、嵌入式工程师为什么必须会？（和面试强相关）
1. **寄存器操作 100% 靠它**  
   比如 STM32 配置 GPIO：
   ```c
   GPIOA->MODER &= ~(0x3 << (2*1)); // 清零PA1模式位
   GPIOA->MODER |= (0x1 << (2*1));  // 设为输出
   ```

2. **高效、省时钟周期**  
   移位+掩码是**单周期指令**，比乘除法、循环快得多，嵌入式必用。

3. **精准控制每一位**  
   硬件寄存器每一位都对应一个功能，只能用位操作单独改，不能动其他位。

# 六、超简总结（背下来）
- **移位**：把二进制位搬到想要的位置（×/÷2ⁿ）
- **掩码**：用 `&` 过滤，只留关心的位
- **移位+掩码**：**精准操作某几位，不影响其他位** → 嵌入式底层核心技能
