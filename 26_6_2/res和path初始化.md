问得**特别关键**！这是 C++ 最基础、但新手最容易懵的地方！

我用**最通俗、最准确**的话告诉你：

# 1. 直接回答你的问题
```cpp
vector<string> res;
string path;
```
这两个变量**不是没初始化**，
而是 **C++ 自动帮你初始化好了！**

它们的**初始值**是：

### ✅ `path` 初始值 = **空字符串**
```
path = ""
```

### ✅ `res` 初始值 = **空的动态数组**
```
res = [ ]  （里面一个元素都没有）
```

---

# 2. 为什么它们会自动初始化？
因为：

## **string 和 vector 都是 C++ 的类（class）**
你一写：
```cpp
string path;
```
它就会自动调用**构造函数**，把变量变成**空的、合法的**状态。

这就像：
- 买个新杯子 → 出厂就是**空杯子**
- 买个新盒子 → 出厂就是**空盒子**

你不用手动赋值，它**天生就是空的**。

---

# 3. 用最直观的方式看初始值
```cpp
string path;        // 空字符串
vector<string> res; // 空数组

cout << path << endl;       // 输出：（什么都没有）
cout << res.size() << endl; // 输出：0
```

---

# 4. 回到代码里，它们一开始就是：
```
path = ""
res = [ ]
```

然后进入：
```cpp
backtrack(s, 0, 0, path, res);
```

### **在 C++ 里：
string path; → 自动是空字符串
vector<string> res; → 自动是空数组
不需要你手动赋值！**
