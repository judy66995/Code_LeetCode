# 一、题目到底是什么意思？（超级大白话）
给你一串**只有数字的字符串**，比如：
```
25525511135
```
你要做的只有一件事：

## **在数字之间加 3 个点，把它切成 4 段，变成合法的IP地址！**

---

## 合法IP必须满足 3 条铁规则（死规矩）
1. **必须切成 4 段**，不能多不能少
   比如：`1.2.3.4` ✅｜`1.2.3` ❌
2. **每一段数字必须在 0~255 之间**
   255 ✅｜256 ❌｜-1 ❌
3. **不能有前导零**
   `0` ✅｜`01` ❌｜`012` ❌

---

# 二、这道题用了什么核心知识点？（通俗讲）
## 1. 回溯法 = **试探 + 退回 + 再试探**
就像走迷宫：
- 先走一条路
- 发现走不通
- **退回到上一个路口**
- 换一条路再走

这就是**回溯**。

## 2. 递归 = **自己调用自己**
切第一段 → 切第二段 → 切第三段 → 切第四段
每一段都是同一个函数在跑，只是参数不同。

## 3. 字符串切割 + 合法性检查
每次切 1~3 个字符，检查：
- 有没有前导零
- 是不是 0~255

# 五、回溯到底是什么？（最关键）
我用最简单一句话告诉你：

## **回溯 = 加一段 → 递归 → 递归完了 → 删掉这段，恢复原样**

看代码：
```cpp
path += sub;        // 加一段
backtrack(...);     // 递归
path.resize(oldLen); // 删掉这段，回到加之前的样子
```

这就是：
**试一条路 → 走完 → 退回来 → 试另一条路**
