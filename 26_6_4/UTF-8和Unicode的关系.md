# Unicode 与 UTF-8 完整关系总结
一句话：**Unicode 是字符集（编号标准），UTF‑8 是 Unicode 的一种编码实现（存储/传输规则）**。

## 1. Unicode（字符集）
> 规定：**全世界每个字符对应唯一数字（码点 Code Point）**
- 给所有文字、符号分配序号：`U+0041=A`、`U+4E2D=中`
- 只定义字符→数字映射，**不规定这个数字在内存/硬盘怎么存成字节**
- 码点范围：`U+0000 ~ U+10FFFF`

举例：
`中` 的 Unicode 码点：`U+4E2D`（十进制 19981），仅此编号。

## 2. UTF‑8（编码方案，Unicode 的实现）
> 把 Unicode 码点**转换成二进制字节序列**，用于磁盘、网络、内存存储。
同个码点可以用多种编码：**UTF‑8、UTF‑16、UTF‑32**，三者都是 Unicode 的编码。

### UTF‑8 编码规则（变长1～4字节）
| Unicode码点范围 | UTF-8占用字节 |
| ---- | ---- |
| U+0000～U+007F | 1字节（兼容ASCII） |
| U+0080～U+07FF | 2字节 |
| U+0800～U+FFFF | 3字节（常用汉字在此区间） |
| U+10000～U+10FFFF | 4字节（生僻字、emoji） |

示例：
`中 U+4E2D` → UTF-8 字节：`0xE4 0xB8 0xAD`（3字节）

## 3. 三者区分：Unicode / UTF-8 / UTF-16
1. **Unicode：编号字典**（字符=几号）
2. **UTF-8：变长字节存储**（网页、Linux、JSON默认编码，兼容ASCII）
3. **UTF-16：定长2/4字节**（Windows内核、Java char底层编码）

## 4. 通俗比喻
- **Unicode = 全国居民身份证号（每个字符唯一ID）**
- **UTF‑8 = 身份证号的纸质填写格式（变长排版规则）**
- **UTF‑16 = 另一种填表格式**
同一个身份证号（码点）可以写成不同格式（UTF8/UTF16）。

## 5. 关键易错点
❌ 错误：UTF-8=Unicode
✅ 正确：**UTF-8⊂Unicode编码实现，Unicode≠编码格式**
